About SmartSort AI

Smart Product Comparison & Recommendation System.

Project overview

SmartSort AI is an AI-powered web application that compares two products and returns AI-generated summaries, specifications, ratings, pros & cons, buying advice, and a clear recommendation.

Problem statement

Consumers spend significant time comparing products across multiple websites. SmartSort AI simplifies this with instant, AI-powered comparisons in one place.

Objectives

  • Simplify product comparison
  • Save research time
  • Provide structured AI insights
  • Help users make informed decisions

Technology stack

Frontend: HTML / CSS / JavaScript
Backend: Node.js + Express.js
Database: MongoDB
AI: Claude Sonnet API

Workflow

Open site→ Enter products→ Select category / purpose→ Compare→ Claude analyzes→ Results

Benefits

  • Cuts product research from tabs-and-hours to one screen and seconds
  • Consistent, structured criteria instead of scattered review opinions
  • Buying advice tailored to a stated purpose, not just generic specs
Current build note: this deployment runs entirely client-side and calls the Claude Sonnet API directly from the browser. History here is session-only (in-memory). Login/registration and persistent, multi-device history need the Node.js + Express + MongoDB backend from the PRD — ask and it can be built as a companion service.
